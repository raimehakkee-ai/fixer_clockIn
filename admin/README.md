# ClockIn — Web Admin

Dashboard Admin/HRD (Vite + React 19 + Tailwind CSS 4).

```bash
npm install
npm run dev       # http://localhost:5173 (proxy /api → http://localhost:4000)
npm run build     # typecheck + build produksi
npm run preview   # pratinjau hasil build
```

Konfigurasi opsional di `.env`:

```bash
VITE_API_URL=     # kosongkan untuk memakai proxy dev
```

Panduan lengkap: [`../docs/ADMIN.md`](../docs/ADMIN.md).
